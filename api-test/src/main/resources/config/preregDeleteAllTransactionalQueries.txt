#####  Local / dedicated mosip_prereg: delete leftover test rows at suite setup. One statement per line (DBManager).
#####  Does not touch prereg.reg_available_slot (booking seed) or Spring batch tables.
#####  Restore kiosk counts for appointments about to be deleted, then children before parents.

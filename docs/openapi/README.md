# OpenAPI (consolidated Pre-Registration)

The live spec is generated by springdoc on the host JVM (`:9090`, context `/preregistration/v1`). Swagger UI HTML routes are `@Hidden` and are not listed as API operations.

## Grouped documents

| Group | OpenAPI JSON | Swagger UI |
|-------|----------------|------------|
| application | `/preregistration/v1/v3/api-docs/application` | `/preregistration/v1/application-service/swagger-ui.html` |
| datasync | `/preregistration/v1/v3/api-docs/datasync` | `/preregistration/v1/sync/datasync-service/swagger-ui.html` |
| captcha | `/preregistration/v1/v3/api-docs/captcha` | `/preregistration/v1/captcha-service/swagger-ui.html` |
| booking | `/preregistration/v1/v3/api-docs/booking` | `/preregistration/v1/appointment/booking-service/swagger-ui.html` |

Default `/preregistration/v1/v3/api-docs` is the ungrouped catalog.

## Export from a running local app

```sh
cd docs/openapi
./export-openapi.sh
```

Requires the host app on `:9090`. Writes `application.json`, `datasync.json`, `captcha.json`, and `booking.json` in this folder.
